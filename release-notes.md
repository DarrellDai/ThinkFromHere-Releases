## ThinkFromHere 0.4.1

- 从历史卡片发送新消息后，详情路径立即切到新分支，向下滚动显示新回复。
- 发送等待期间若已切换到其他卡片，保留用户当前位置。
- 修复 Android 推送令牌失效后的自动恢复。

## English

- Sending from a historical card immediately switches the detail path to the new branch, so scrolling down shows the new reply.
- Preserve the current selection when navigating away while a send is pending.
- Recover Android push registration after a token becomes invalid.

包含 Windows x64、macOS universal、Linux deb/tar.gz、Android APK 和 iOS 模拟器包，以及 SHA-256 校验文件。
iOS ZIP 仅适用于模拟器，不是真机安装包。
