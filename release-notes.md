## ThinkFromHere 0.4.3

- Activity 中的 Flag 改为实心红旗。
- 改善手机边缘滑动、输入区滑动、详情关闭动画，修复关闭详情时侧边栏闪现。
- 展开屏支持调整画布列表大小和拖动列表，优化列表开关动画。
- 澄清问题的回答显示在卡片提示下方。
- 修复 Agent 卡片拆解时的连接选择；持久保存任务恢复检查点，并在重启恢复前确认任务结果。

- Use solid red flags in Activity.
